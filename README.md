# Kaleeswaran Irulaiya — Angular Portfolio Website

Built completely in **Angular 19 Standalone Components**, matching the Figma/Pinterest reference layout with warm forest green (`#1A3C2B`), sunflower yellow (`#F59E0B`), and off-white cards.

## Key Features
- **Hero Section**: Dashed "Hello There!" crosshair tag, bold yellow title, action buttons, organic yellow backdrop, rotating "HIRE ME" sticker badge, and floating skill chips.
- **Animated Marquee Ticker**: Continuous animated yellow ticker banner with star glyphs.
- **Services I Provide**: Rounded cards with icon badges and "Learn more →" links.
- **About Me Section**: Deep forest green section with metrics (25+ repos, 100% CRUD accuracy, 1+ years experience), "Download CV", and stylized signature.
- **Tools & Tech Stack**: 6 circular percentage proficiency badges (Java 94%, Angular 95%, Spring Boot 92%, etc.).
- **My Latest Projects**: Showcase cards linked to 25+ GitHub repos at https://github.com/kaleez17.
- **Academic & Professional Journey**: Education and Work Experience side-by-side cards.
- **Pricing Model**: 3 tiers with highlighted full-time developer card.
- **Contact Us**: Direct channels and full interactive inquiry form.
- **Free AI Assistant**: In-browser client-side agent answering questions with zero cost.

## How to Run
```bash
unzip kaleeswaran-3d-portfolio.zip -d kaleeswaran-portfolio
cd kaleeswaran-portfolio
npm install
npm start
```
Open `http://localhost:4200`.
